### 1. `ddlj-title` — DDLJ का title Aditya Chopra ने नहीं दिया था?

- **Facts:**
  - The title comes from the song "Le Jayenge Le Jayenge" in *Chor Machaye Shor* (1974); the film carries a "Title suggested by" credit. [Wikipedia](https://en.wikipedia.org/wiki/Dilwale_Dulhania_Le_Jayenge)
  - It passed *Sholay* in 2001 as the longest-running film in Indian cinema and reached 1,000 weeks at Maratha Mandir in December 2014. (same page)
  - In February 2015 Maratha Mandir announced the run would end at 1,009 weeks; it was reinstated after fans and the producers stepped in. (same page)
  - By 16 March 2020 it had run 1,251 weeks, until the COVID lockdown shut the theatre. (same page)
- **Payoff:** Kirron Kher suggested the title.
- **Images:** Posters and publicity stills: credited commentary.
- **Lock before use:** "First film with a 'title suggested by' credit" is the page's "believed" wording, so don't say "first". Cross-check "longest-running" with a trade source. Find an interview for the Kirron Kher credit.

## How to produce the next one

Copy the template, then:

```powershell
# from repo root
npm run short -- lint SLUG
npm run short -- say SLUG
npm run short -- still SLUG --url IMAGE --source PAGE --credit "Studio" --label "Film (Year): what it shows" --name f1
npm run short -- stills SLUG
npm run short -- render SLUG --draft
# watch draft.mp4; then voice (record or --edge) and full render
```

Checklist before render: hook on frame 0, source on every fact, no textbook Hindi, stills labelled, captions above the Shorts UI, loop shares a hook word.
